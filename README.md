# Convertion for Homebrew

[Convertion](https://convertion.app) adds a right-click menu to the Finder to
convert and compress images, video, audio and PDFs.

```bash
brew install --cask supahfunk/tap/convertion
```

Then open Convertion once and turn the extension on in
System Settings → General → Extensions → Convertion (ⓘ) → File Providers.

Requires macOS 14 or later on Apple Silicon.
